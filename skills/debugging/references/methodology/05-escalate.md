# Phase 5: User Decision Escalation

Escalate only when evidence is exhausted and the remaining choice has policy, product-behavior, scope, or risk implications; when multiple valid fixes require user preference; or when two more rounds failed after independent reframing. Also ask before any gated action described in `SKILL.md`.

Do not ask when one runtime query can decide, when the obvious safe next step is available, or before the reframing threshold.

```markdown
## Decision needed

**Observed facts**
- <verbatim fact and source>
- <what evidence rules in and out>

**Decision**: <one sentence>

| Option | Scope | Risk | Effort |
|---|---|---|---|
| A | ... | ... | ... |
| B | ... | ... | ... |

**Recommendation**: <option and evidence-based reason>.
```

Ask one decision at a time. After the user chooses, the choice still requires reversible causal confirmation.
